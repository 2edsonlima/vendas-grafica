# 🛍️ Catálogo Virtual com Painel de Administração

Este é um projeto Full Stack de um catálogo de vendas online. Ele permite que clientes visualizem produtos e façam pedidos diretamente pelo WhatsApp, enquanto o lojista possui um painel administrativo oculto para gerenciar o estoque.

## ✨ Funcionalidades

* **👁️ Visão do Cliente:** Catálogo limpo, barra de pesquisa funcional e botão de compra integrado com WhatsApp.
* **⚙️ Visão do Administrador (`/admin`):** Área restrita para cadastro, edição e exclusão de produtos em tempo real.
* **📱 Responsividade:** Interface moderna e adaptada para funcionar perfeitamente em celulares e computadores.
* **🐳 Dockerizado:** Configuração completa com Docker e Docker Compose para rodar o projeto com um único comando.

## 🚀 Tecnologias Utilizadas

**Frontend:**
* React.js (com Vite)
* CSS3 puro (Design Moderno e Responsivo)

**Backend:**
* Node.js
* Express.js
* CORS

**DevOps:**
* Docker
* Docker Compose
